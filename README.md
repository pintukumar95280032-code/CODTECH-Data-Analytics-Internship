# CODTECH-Data-Analytics-Internship
Task 3: Interactive Dashboard Development
Project Overview:
In this task, I developed an interactive web-based dashboard using Dash and Plotly to visualize and analyze housing market data. The objective was to transform static data into a dynamic interface where users can explore trends and correlations visually.

Key Features:

Dynamic Data Loading: Successfully integrated the USA_Housing.csv dataset into the Dash framework.

Interactive Price Distribution: Created a histogram allowing users to analyze house price frequency with hover-over data details.

Correlation Analysis: Developed a scatter plot with an OLS trendline to visualize the relationship between 'Average Area Income' and 'Price'.

User Interaction: Implemented zoom, pan, and hover tools for a deeper dive into specific data points.

Tools & Technologies:

Libraries: Dash, Plotly, Pandas.

Environment: Google Colab.

Programming: Python.
